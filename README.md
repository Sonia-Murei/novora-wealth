# Novora Wealth

Novora Wealth is a personal finance management web application that enables users track income and expenses, manage monthly budgets, set savings goals, and visualize their financial progress through an interactive dashboard. It was built using **Python**, **Flask**, **PostgreSQL**, **HTML**, **CSS**, **Bootstrap**, **DataTables**, and **Chart.js**, and is deployed on **Render** with a **Neon PostgreSQL** database.

## 🌐 Live Demo

https://novora-wealth.onrender.com


## ✨ Key Features

- Password-protected user accounts
- Income and expense tracking
- Monthly budget management
- Savings goal tracking
- Interactive financial dashboard with charts
- Responsive Bootstrap interface
- PostgreSQL database integration
